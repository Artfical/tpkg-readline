readline 8.2 for tOS
====================

Built from the release tarball beside this package (readline-8.2.tar.gz), unmodified, with prefix /system/pkg/readline: headers in include/, libraries in lib/. gcc finds them by itself (its specs list this folder). License: GPL-3.0+ (LICENSE).
glibc: its programs and shared libraries are linked dynamically against the GNU C Library, which tOS's base system carries in /lib64 and /lib/x86_64-linux-gnu.
